# AutoHotkey

`hotkeys.ahk` (AutoHotkey v2): global hotkeys. Currently **Win+K** opens a Bluetooth picker (Enter connects, Ctrl+D disconnects) from the toolnest repo, because Windows 11 turned Win+K into Cast.

To borrow it: install AutoHotkey v2 (`winget install AutoHotkey.AutoHotkey`) and double-click the file. Put a shortcut to it in `shell:startup` to run it at login. The Bluetooth hotkey also needs the toolnest repo.
