# Wallpapers

A growing collection. Drop new images here (JPG/PNG, 1920x1080 or larger) and commit them on a branch via a PR. Keep each file to a few MB so the repo stays light; if the collection gets big, move it to its own repo or a cloud folder.

| File | Source |
|---|---|
| `vladstudio_sabaduri_forest_1920x1080.jpg` | Vlad Gerasimov (vladstudio.com) |

```powershell
.\windows\wallpaper.ps1 -Name vladstudio_sabaduri_forest_1920x1080.jpg   # a specific one
.\windows\wallpaper.ps1 -Random                                          # pick any from the collection
```
