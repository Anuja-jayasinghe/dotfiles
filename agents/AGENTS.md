# Global agent instructions

Shared by every coding agent on every machine (Claude Code reads it through `~/.claude/CLAUDE.md`).

## Environment
- Windows is the main machine; the work Mac and WSL are secondary.
- All git projects live in `C:\gitprojects` (`~/gitprojects` elsewhere).
- Dotfiles repo (configs, one folder per tool): `C:\gitprojects\dotfiles`.
- Toolnest repo (all utility scripts, run with `just`): `C:\gitprojects\toolnest`. Put new scripts there, not in dotfiles.
